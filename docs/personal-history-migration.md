# Personal history migration (read-only archive)
This migration preserves UUID owner boundaries and legacy user/assistant transcripts. It does not create fake LangGraph checkpoints, replay tools, migrate workspace data, or assert that legacy runs can resume. Imported conversations are explicitly read-only; users start a fresh conversation for new work. The original Operly data remains untouched until parity is verified. The importer rejects unsupported roles, noncanonical IDs, missing canonical imported owners, drift in approved counts and destination collisions. Use an approved private three-database runner, a reviewed snapshot/delta procedure, and a backup. Apply the archive schema manually before enabling `DRAGONZPYDER_PERSONAL_HISTORY_ARCHIVE_ENABLED`. Do not enable that flag until archived rows are reconciled and real cross-account browser tests pass. This PR contains no production data transfer.
